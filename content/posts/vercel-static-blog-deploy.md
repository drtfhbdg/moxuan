以前自己买云服务器建站，还得搞个 Nginx 做反向代理，不仅费钱，而且节点单一，国内访问有时抽风。

现在彻底拥抱了 Vercel 这个神器。只要是静态的前端项目（比如我现在用的 Hugo，或者纯前端的 Vue 项目），直接绑定 GitHub 仓库，每次 `git push` 后，它全自动帮你构建部署。

最香的是，Vercel 自带全球的 CDN 加速，还免费帮你配置好了 SSL 证书。只要自己在后台绑定一个域名，剩下的什么运维工作都不用管了，纯纯的省心。
