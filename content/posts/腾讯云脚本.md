##### 第一步：换腾讯云内网 apt 源

```bash
cp /etc/apt/sources.list /etc/apt/sources.list.bak

tee /etc/apt/sources.list << 'EOF'
deb http://mirrors.tencentyun.com/debian bookworm main contrib non-free non-free-firmware
deb http://mirrors.tencentyun.com/debian bookworm-updates main contrib non-free non-free-firmware
deb http://mirrors.tencentyun.com/debian-security bookworm-security main contrib non-free non-free-firmware
EOF

apt update
```

##### 第二步：限速 192 Mbps

```bash
tc qdisc add dev ens5 root tbf rate 192mbit burst 32kbit latency 400ms
```

------

##### 第三步：开机自动限速

```bash
tee /etc/systemd/system/tc-limit.service << 'EOF'
[Unit]
Description=TC rate limit 192mbit
After=network.target

[Service]
Type=oneshot
ExecStart=/sbin/tc qdisc add dev ens5 root tbf rate 192mbit burst 32kbit latency 400ms
ExecStop=/sbin/tc qdisc del dev ens5 root
RemainAfterExit=yes

[Install]
WantedBy=multi-user.target
EOF

systemctl enable tc-limit.service
systemctl start tc-limit.service
```

**验证限速是否生效：**

```bash
tc qdisc show dev ens5
```

**临时取消限速：**

```bash
tc qdisc del dev ens5 root
```

修复方法是先删掉再加，更新 service 文件：

```bash
# 先手动清掉现有的 qdisc
tc qdisc del dev ens5 root

# 更新 service 文件，ExecStart 改成先删再加
tee /etc/systemd/system/tc-limit.service << 'EOF'
[Unit]
Description=TC rate limit 192mbit
After=network.target

[Service]
Type=oneshot
ExecStartPre=-/sbin/tc qdisc del dev ens5 root
ExecStart=/sbin/tc qdisc add dev ens5 root tbf rate 192mbit burst 32kbit latency 400ms
ExecStop=/sbin/tc qdisc del dev ens5 root
RemainAfterExit=yes

[Install]
WantedBy=multi-user.target
EOF

# 重载并重启服务
systemctl daemon-reload
systemctl restart tc-limit.service
systemctl status tc-limit.service
```

关键是 `ExecStartPre=-/sbin/tc qdisc del dev ens5 root` 这一行，前面的 `-` 表示即使删除失败（比如本来就没有）也继续执行，不报错。
